# PPT课件使用说明

本文件夹提供了电机开发教程的 **PPT教学课件**，帮助学习者系统掌握电机控制的理论与实践。

## 📌 包含内容

- `chap01` 电机控制概述  
- `chap02` 直流有刷电机入门  
- `chap03` 舵机入门  
- `chap04` 步进电机入门  
- `chap05` BLDC直流无刷电机入门  
- `chap06` 串口屏显示驱动教程  
- `chap07` 闭环控制系统基础  

## 💡 使用建议

- 课件内容与 B站视频同步，适合配合视频<https://www.bilibili.com/video/BV122JEzaE2n/>学习  
- 推荐按照章节顺序学习，从基础概念到具体电机类型，最后学习闭环控制
- 建议配合实际硬件进行实践，加深理解
- 每章课件包含理论基础和实际应用示例

## 🚀 学习路径

1. **基础概念**：chap01 概述 → chap07 闭环控制系统基础
2. **电机类型**：chap02 直流有刷电机 → chap03 舵机 → chap04 步进电机 → chap05 BLDC无刷电机
3. **外设驱动**：chap06 串口屏显示驱动
4. **系统整合**：chap07 闭环控制
5. **后续课程**：chap08以及以后的课程还在努力制作中
